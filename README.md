Care Circle started from a simple question: when someone receives a terminal diagnosis, how do they and their loved ones find the right support? Patients and caregivers often have to piece together hospice options, care services, and community support on their own, at the hardest moment of their lives. Care Circle aims to bring those resources together in one calm, easy-to-use place.

The front end is built on the SB Admin 2 Bootstrap template and customized for a dashboard-style experience. A Node.js and Express API serves the app's data and will grow as features are added.

## Planned Features

- A directory of care support and hospice resources
- Profiles for patients and caregivers to save the resources that fit their needs
- Simple, accessible design for users who may be stressed, tired, or new to technology

## Installation

1. Clone the repo
2. Run `npm install`
3. Run `node server.js`
4. Open `http://localhost:3000` in your browser
